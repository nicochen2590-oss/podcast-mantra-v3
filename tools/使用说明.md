# 页面设计工作台 · 使用说明

这是 Podcast Mantra 的**页面设计工作台**：打开就已经有 3 个设计好的完整页面（封面、文案、背景都摆好了），你可以直接在上面排版修改，而不用从空白画布开始。

---

## 怎么打开（任选一种）

- **双击 `启动编辑器.command`**（推荐）：会启动本地服务并用浏览器打开
- 或直接双击 `design-studio.html`

> 建议用 Chrome 或 Edge。

## 怎么编辑

**改文字**
- **双击**画布上的任意文字 → 直接改字 → 按 Enter 或点别处保存
- 或选中文字后，在右侧「元素属性」里改字号、颜色、字体（衬线/无衬线）、对齐、字距

**移动 / 缩放 / 旋转**
- 拖动元素 → 移动
- 拖四个角的小圆点 → 缩放
- 拖顶部蓝色圆点 → 旋转（按住 Shift 按 15° 吸附）

**换封面图**
- 选中图片元素 → 按 Delete 删掉 → 从左侧素材库点一张新的添加
- 也可点「上传透明图片」传自己的 PNG

**加东西**
- 左侧「添加元素」：+文字 / +形状（矩形、圆、线条）
- 左侧素材库：点封面添加到当前页

**图层（右侧）**
- 拖动图层 → 改层级（越靠上越在前）
- 眼睛 → 显示/隐藏；锁 → 锁定；× → 删除元素（**不删素材库原图**）

**页面**
- 点 `+` 新建空白页；单击切换；双击改名；鼠标移上去点 × 删除

**背景**
- 右侧「页面背景」：暖纸 / 海面渐变 / 深夜黑，或自定义颜色

---

## 保存 / 预览 / 备份

- 每次改动**自动保存**到浏览器本地（右上角显示「已保存」）
- 点「▶ 预览」看成品，按 Esc 返回
- 点「导出」下载完整项目 JSON（含所有图片），换电脑用「导入」恢复
- **清理浏览器数据前一定先「导出」备份**
- 同时开两个窗口，改动会自动同步

## 快捷键

| 按键 | 作用 |
|---|---|
| 双击文字 | 直接编辑文字 |
| Delete | 删除选中元素 |
| Ctrl/⌘ + Z | 撤销 |
| Esc | 取消选中 / 退出预览 |
