# Podcast Mantra · 使用说明（免登录版）

## 一句话

打开就进书斋，没有登录页、没有注册。你自己的记号与逐字稿存在**这台设备的浏览器**里。

## 现在页面长什么样

- **书斋（/dashboard）**：左边是栏目，中间是书架。
  - 「环绕」= 手绘书环绕着你转，滚轮能转、能拖、停在一本上会浮到中间翻开。
  - 「书阵」= 一次铺满的密集封面墙，适合快速扫。
  - 「网格 / 列表」= 规整的卡片，信息最全。
  - 手机上默认进「网格」，因为环绕在小屏上太挤。
- **详情页（/episode/…）**：封面、概要、思维导图、播放器（有音频时）、逐字稿。
- **第一本书「芬兰的四季：从主显节到桑拿」是示例**，带完整逐字稿与导图，点开就能看到产品最终长什么样。

## 五件能做的事

1. **逛**：55 期真实播客的公共索引（标题 / 节目 / 时长 / 封面 / 原链接），只读。
2. **收一条**：点「粘一条链接」，贴小宇宙单集链接，自动抓标题、封面、时长、音频直链，存进本机。
3. **贴逐字稿**：进任意一期的详情页 → 逐字稿 → 「粘贴逐字稿」。
   - 按句子自动切成 42~150 字的小段；
   - 行首带 `[12:34]` / `00:12:34` 时间码的，照你的时间走；没有就按语速估算；
   - 存完自动生成上面那张思维导图，点导图节点能跳回对应段落。
4. **留记号**：卡片上的「留个记号」——花朵评分、一句余音、换一张专辑。会进「余音手账」「月度书架」「词云洞察」。
5. **搜**：顶部搜索框搜标题 / 节目 / 简介 / 余音，即时过滤。

## 数据在哪

浏览器 localStorage 三个键：

| 键 | 存什么 |
|---|---|
| `pm_guest_library_v1` | 自己粘进来的期、自己建的专辑 |
| `pm_episode_meta` | 花朵评分、余音、归属专辑 |
| `pm_guest_transcripts_v1` | 自己贴的逐字稿与据此生成的导图 |

⚠️ 换设备、换浏览器、清缓存都会丢。要跨设备，得把 Supabase 登录接回来（见下）。

## Supabase 还在，只是不参与页面

- `src/lib/supabase/`、`src/app/api/*`、`supabase/*.sql` 都原样保留。
- 页面不再调用 `auth.getUser()`，也不再依赖云端，**云端连不上也照常打开**（之前国内网络连不上 supabase 域名就是这个坑）。
- 想恢复「登录后云端同步」：恢复 `src/app/login/`、`src/app/auth/callback/`，把 `dashboard/page.tsx` 与 `episode/[id]/page.tsx` 改回读 user 分支即可。原代码在 git 之外没有备份，建议先复制一份再改。

## 本地启动

```bash
cd ~/Workbuddy/2026-11-17-19-21-08/podcast-mantra
npm run dev
```

打开 http://localhost:3000 。手机同一 Wi-Fi 下可用终端里显示的 Network 地址访问（`next.config.mjs` 的 `allowedDevOrigins` 里要加上那个 IP，否则开发环境下页面不会水合）。

## 已知边界

- 只支持**小宇宙**链接解析，B站 / 抖音 / 小红书还没接。
- 公共索引里没有音频（版权原因），播放一律链回原平台；只有自己粘的小宇宙链接带音频直链。
- 逐字稿时间戳是**估算**的，不是转写引擎给的；要真实时间戳得接 ASR（`/api/transcribe` 还在，需要 Supabase Storage + 硅基流动 Key）。
- 「稍后听」「知识库问答」还是占位。

## 2026-11-25 补记：这一版新增了什么

- **开屏页**：`/` 是一条环形回廊（three.js），两侧挂着 9 档真实播客的封面（忽左忽右 / 随机波动 / 声动早咖啡 / 壮游者 / 商业就是这样 / 不合时宜 / 声东击西 / 跳岛FM / 文化有限），滚轮或拖拽往里走，点封面靠近，再点一次进书斋。
- **导航分四组**：DISCOVER（首页、全局搜索）/ LIBRARY（内容库、稍后听、主题专辑、待处理、月度书架）/ KNOWLEDGE（余音手账、知识图谱、AI 问答、词云）/ SYSTEM（数据备份、设置）。没做的栏目明确留空，不放假按钮。
- **内容库**：35 期（10 档节目 / 11 个品类），支持多选 → 删除 / 移到别的专辑。
- **详情页五个栏目**：概览（A 一句话 / B 背景 / C 核心内容 / D 结论 / E 适合谁）、逐字稿（章节导航 + 搜索 + 复制 + 存金句 + 加进手账 + 标记 + 导出）、精华（核心观点 / 金句 / 方法 / 案例 / 问题）、笔记、关联（相似内容 / 相关专题 / 关联观点）。
- **自动转写**：本机 whisper（Apple GPU，`mlx` 后端，large-v3-turbo）。打开没有稿的期会自动开始，逐片推进、可随时停，关掉页面下次接着转；单片失败会自动重试。
- **整理（概要/章节/观点/金句）**：默认本地规则；配置 `DEEPSEEK_API_KEY` 后自动切换成大模型整理（同一个 JSON 结构，质量高一档）。
- **专辑内部页**：收藏内容 / 专题摘要 / 关键观点 / 用户笔记 / 关联专辑。
- **数据备份**：SYSTEM → 数据备份与导出，可导出/导入整份 `localStorage`。

### 关于质量

规则版只能"抽取"，不能"理解"：概览会变成抽一句原文，核心观点会挑到过渡句。要做到你要求的 A–E 概览、有依据的观点、方法/案例/问题的区分，必须用大模型。接法已经写好（`tools/asr_server.py` 里的 `analyze_with_llm`），只要在 `.env.local` 里加：

```
DEEPSEEK_API_KEY=sk-...
```

重启本地识别服务即可生效，按一期 1 小时节目估算，成本大约 ¥0.02–0.08。

### 2026-11-25 第二轮：0 成本路线

用户确认不接付费大模型。相应调整：

- 概览 / 章节 / 观点 / 金句全部由**本地规则**生成，页面上明确标注「本地规则整理」。
- 规则版能保证的是：结构完整、每句都有时间码、金句逐字来自原文、方法与案例「有就列、没有就说没有」。
- 规则版**做不到**的是：真正读懂论证关系、区分论点与论据、写出有洞察的观点。要那一步只能上大模型（代码已接好，填 `DEEPSEEK_API_KEY` 即生效）。
- 删掉了：逐字稿的中英双语切换、段落「标记」、稍后听、设置、词云页的每日签到。
- 内容库扩到 91 期（11 个品类），标题含「爱情/恋爱/情感/分手/前任/相亲/婚姻/暧昧」的一律跳过。

### 2026-11-25 第三轮：每日一荐 + 三大页面

- **数据分层**：公共推荐池 `src/data/recommendations.json`（30 条，只读）；私人内容仍在本机 localStorage。收藏推荐 = 复制一条进私人库，公共池永不被写。
- **每日精选**：`hash(日期) % 池子大小`，同一天所有访客一致，无需后端。
- **知识抽签**：随缘 / 主题 / 时间三种模式；当日结果存 `pm_draw_today_v1`，刷新不变；「再抽一次」会避开上一条；抽签卡片有纸签展开动画（0.95s）。
- **导航**：DISCOVER（首页、每日一荐）/ SEARCH（全局搜索）/ MY LIBRARY（内容库、主题专辑、待处理）/ KNOWLEDGE / SYSTEM。月度书架入口已删除。
- **三个页面的视觉分工**：首页=独立刊物封面（大刊头、书单、最近动作）；每日一荐=仪式感纸签（居中、大抽签按钮、展开卡片）；搜索=检索效率（粗描边搜索框、分组结果、筛选条）；内容库=信息密度（统计条、状态/排序、三视图）。
- 待办：内容库的多选导出、类型筛选（目前只有播客一种类型）。
